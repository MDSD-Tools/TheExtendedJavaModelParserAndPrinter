# Installation

## Requirements

* The minimum required version to run the extended JaMoPP is Java 17.
* For the use in Eclipse, the minimum required version is Eclipse Modeling Tools 2022-12.

## Installation

For the extended JaMoPP, we provide the artifacts via Maven Central and a P2 Update Site:

* Maven Central (coming soon)
* P2 Update Site (coming soon)

Additionally, there is the following nightly P2 update site which provides artifacts with the latest changes:

* [Nightly P2 Update Site](https://updatesite.mdsd.tools/extended-java-model-parser-and-printer/nightly/)

:::warning

The nightly update site can have different requirements (e.g., on the minimum Java version) compared to the latest release. So, before using it, please check the [`CHANGELOG` on the `develop` branch](https://github.com/MDSD-Tools/TheExtendedJavaModelParserAndPrinter/blob/develop/CHANGELOG.md) for the latest changes.

:::
